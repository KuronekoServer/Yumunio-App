# Web版との同期とアップデート

アプリは検証済みの接続先を、同じWebViewのHTTPS画面として開きます。最新版のWeb UIと共同編集コードが読み込まれます。端末ごとのYjs client IDと接続を使うため、同じアカウントの別端末を同じ編集インスタンスとして使い回しません。

同時入力はサーバーのYjsとWebSocketに任せます。ランチャーには文書キャッシュ・ポーリング書き込み・別の同期プロバイダーを設けません。再接続や差分再送、現在の権限確認もサーバーの編集画面で処理します。

保存済みの接続先を選ぶと、公開情報の検証後に開きます。新しい接続先は確認結果を見てから開きます。health・表示設定・認証は並行して確認し、HTTPS証明書・転送先・サイズ・応答形式の検査を継続します。ログイン情報を一覧に保存せず、リモートページへTauriのIPC権限を渡しません。

古いサーバーへ接続した場合は、そのサーバーが提供する機能になります。Yumunio本体とアプリをそれぞれ更新してください。
