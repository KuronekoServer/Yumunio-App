# アプリの画面デザイン

## 方針

接続先の確認とログインへの移動を順番に行う画面です。Web版のライト・ミッドナイトと同じ基本色、密度の高いサイドバー、控えめな角丸を使います。保存済みサーバーは、確認に成功したら1回の選択で開けます。ワークスペース本体は接続先のNext.js画面を表示し、shadcn/ui、本文内DB、表・かんばん・カレンダー・タイムライン、詳細パネル、自動Yjs共同編集の変更を共通で受け取ります。アプリ独自のYjs接続や書き込みの定期同期は追加せず、プロバイダーの二重起動を避けます。

空の状態に架空のサーバーを並べません。接続前にオンラインを示す表示もしません。「接続を確認」は、ネイティブ側が実際に応答を確認したときだけ表示します。右側の紙面イメージは装飾で、利用者の文書や利用可能な追加機能を示すものではありません。

## 画面一覧

| 画面・状態   | 内容                                                |
| ------------ | --------------------------------------------------- |
| 接続前       | サーバーURL、入力例、接続確認、保存済みのサーバー   |
| 確認中       | 入力と重複送信を止め、確認中の表示に切り替える      |
| 接続確認後   | サーバーの公開名と正規URL、ログイン画面を開くボタン |
| 接続失敗     | URL・応答・証明書・認証無効など、修正に必要な案内   |
| マイサーバー | 接続したサーバーの再選択と端末内の接続先削除        |
| 接続の手順   | URL入力、接続先確認、ログインの3段階                |
| 設定         | 端末に合わせる・ライト・ダーク、保存する情報の説明  |
| サーバー内   | 既存の Yumunio 画面と、選択画面に戻る操作           |

## 寸法

| 対象               | 基準                                                     |
| ------------------ | -------------------------------------------------------- |
| デスクトップ       | 1280 × 840、サーバー一覧228px、メイン左右余白46px        |
| 大きいデスクトップ | 1440 × 960、接続領域と装飾の2列                          |
| タブレット         | 1024 × 768、サーバー一覧と接続領域の2列                  |
| スマートフォン     | 390 × 844、左右余白24px、下部ナビゲーション              |
| 最小幅             | 320px、左右余白17px、説明を折り返す                      |
| 折りたたみ         | 展開時は幅に応じた2列。対応WebViewではヒンジを列間にする |
| 主要ボタン         | デスクトップ47px、モバイル50px以上                       |

文字はOSの日本語対応システムフォントを使用し、外部フォントサービスへの接続は不要です。入力欄はモバイルで16pxにし、iOSの入力時拡大を避けます。フォーカスを可視化し、ネイティブdialogでフォーカス制御とEscapeによる終了を提供します。モーション軽減の設定を尊重します。

## pen.dev

ローカルのデザイン原本は `Yumunio-App.pen` を使用します。暗号化された `.pen` は pen.dev MCP だけで操作します。公開用の説明はこの文書と実装コードに置き、原本・一時スクリーンショット・検証データを Git に含めません。

2026-10-20 に pen.dev デスクトップ版のMCPで、アプリ専用キャンバスに次の8画面を作成しました。各画面をPNGへ書き出し、配置、折り返し、ライト・ダークの表示を確認しています。同日、利用者による保存後、ディスク上の原本更新を確認しました。

1. `01 — Desktop / Connect`（1280 × 840）
2. `02 — Desktop / Verified server`（1280 × 840）
3. `03 — Phone / Connect`（幅390px、OSの安全領域を含めて内容に合う高さ）
4. `04 — Phone / Saved servers`（幅390px、保存済みサーバーのダイアログ）
5. `05 — Tablet / Connect`（1024 × 768）
6. `06 — Foldable / Two segments`（左右の画面とヒンジ）
7. `07 — Dark / Connect`（1280 × 840）
8. `08 — Phone / Connection error`（幅390px、内容に合う高さ）

URL入力、主要ボタン、保存済みサーバー、接続確認表示、下部ナビゲーションの5種類を再利用可能な部品として作成しました。基礎フレームを含めてトップレベルは14件、未完了を示す placeholder は0件です。ライト・ダークは `appAppearance` と `app.*` の色変数で切り替えます。ロゴは公開ソースのアプリアイコンを参照します。

実装の文字はOSフォントを使用し、キャンバスでは Noto Sans JP を使用します。右側の紙面プレビューは装飾の表現に差があります。新たな画面を追加するときは既存ノードと部品を読み取り、原本を直接更新して検証してください。
